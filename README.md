## ✨ O que é

O **README Builder** é uma ferramenta web gratuita para montar o README do seu perfil do GitHub **sem escrever uma linha de Markdown**. Você preenche, vê o resultado em tempo real e baixa o `README.md` pronto.

Sem cadastro, sem instalar nada, sem configurar API — e funciona no computador, no tablet e no celular.

## 🚀 Como usar

1. Acesse **[readmebuilderv.vercel.app](https://readmebuilderv.vercel.app)**
2. Digite seu **username do GitHub** — seus dados são puxados automaticamente
3. Escolha um template ou personalize: textos, ícones, cards, redes sociais
4. Clique em **Download README.md** (ou copie o Markdown)
5. No GitHub, crie um repositório **com o mesmo nome do seu usuário** (ex.: `seu-usuario/seu-usuario`) e coloque o arquivo na raiz

Pronto — o README aparece no topo do seu perfil. ✨

## ❓ Perguntas frequentes

<details>
<summary><b>Preciso pagar ou criar conta?</b></summary>
<br />
Não. É gratuito e não pede cadastro nem login.
</details>

<details>
<summary><b>Os números dos cards ficam desatualizados?</b></summary>
<br />
Não. Stats, sequência, linguagens, troféus e gráfico de atividade são gerados no momento em que alguém abre seu perfil, com seus dados públicos atuais.
</details>

<details>
<summary><b>Meus dados ficam salvos em algum servidor?</b></summary>
<br />
A configuração do editor fica só no seu navegador. Os cards consultam apenas dados <b>públicos</b> do seu perfil do GitHub.
</details>

<details>
<summary><b>Como coloco a cobrinha (snake)?</b></summary>
<br />
Ative o plugin <b>Snake</b>, clique em <b>Baixar snake.yml</b> e salve o arquivo em <code>.github/workflows/snake.yml</code> no repositório do seu perfil. Depois rode a Action uma vez em <i>Actions → Generate snake animation → Run workflow</i>.
</details>

<details>
<summary><b>Funciona no celular?</b></summary>
<br />
Sim. A interface se adapta a celulares, tablets e computadores, e o download do <code>README.md</code> funciona também no iPhone e no Android.
</details>
